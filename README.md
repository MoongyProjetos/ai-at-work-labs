## 🎯 About the Workshop

**AI at Work Labs** is a practical workshop designed to demonstrate how Generative AI can support day-to-day professional activities, helping people:

* Increase productivity
* Reduce repetitive tasks
* Analyze information faster
* Create and improve content
* Organize ideas and information
* Automate parts of their workflow
* Explore alternatives and generate ideas
* Make better-informed decisions

The workshop is **tool-agnostic**. Microsoft Copilot is an important part of the workshop, but we will also explore tools such as **ChatGPT, Gemini, Claude** and other AI solutions when they are relevant to the use case.

The objective is not to teach participants how to use one particular product.

> **The objective is to teach people how to use AI effectively at work.**

---

## 🧠 What You Will Learn

By the end of the workshop, participants should be able to:

* Understand the fundamentals of Generative AI
* Understand the strengths and limitations of AI tools
* Write clearer and more effective prompts
* Improve AI-generated results through iteration
* Use Microsoft Copilot in everyday work scenarios
* Use AI to summarize and analyze information
* Create documents, presentations and other content
* Organize tasks and ideas using AI
* Identify opportunities to automate repetitive work
* Apply AI to different business functions
* Validate AI-generated information
* Recognize privacy, security and responsible-AI considerations

# 🧩 Workshop Philosophy

This workshop follows a simple principle:

> **AI should augment human work, not replace human judgment.**

The focus is therefore not on memorizing prompts or learning a collection of AI tricks.

Instead, participants learn how to:

1. Understand the task
2. Identify where AI can help
3. Provide the right context
4. Ask effectively
5. Evaluate the result
6. Iterate when necessary
7. Apply human judgment
8. Improve the workflow

---

# 💬 Prompting Framework

Throughout the workshop we will use a simple framework for constructing effective prompts:

| Element          | Question                            |
| ---------------- | ----------------------------------- |
| **Context**      | What does the AI need to know?      |
| **Result**       | What do I want to achieve?          |
| **Instructions** | How should the task be performed?   |
| **Format**       | How should the result be presented? |

A good prompt does not need to be complicated.

It needs to provide **the information necessary for the AI to understand the task**.

# 🔐 Responsible Use

AI tools should be used according to the policies of your organization and the terms of the tools being used.

Do not submit confidential, sensitive or personal information to an AI system unless you are authorized to do so and the appropriate protections are in place.

Always review AI-generated content before using it professionally.

> **AI can generate an answer. The responsibility for using that answer remains with the professional.**

---

# 🚀 The Goal

The goal of this workshop is simple:

> **Find ways to make your work better, faster and more effective with AI.**

Not every task needs AI.

Not every AI answer is correct.

And not every new AI tool needs to become part of your workflow.

The skill is knowing **when AI can help, how to use it effectively, and how to evaluate what it produces.**
